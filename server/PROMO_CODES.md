# Промокоды ECHO (только VPS)

Промокоды создаются **только на сервере**, без публичного API для выпуска наград.
Работают для авторизованных ECHO-аккаунтов через существующий экран
**Настройки → Ввести код**.

Откройте SSH на VPS:

```bash
cd /var/www/echo-game/server
node scripts/create-promo.js --code ECHO2026 --type premium_pack --amount 1 --limit 100
```

Другие примеры:

```bash
# 250 ECHO Coins, можно активировать до 31 декабря 2030 года (UTC)
node scripts/create-promo.js --code NEWYEAR250 --type coins --amount 250 --expires 2030-12-31T23:59:59Z

# Два обычных пака для первых 50 игроков до указанной даты
node scripts/create-promo.js --code BONUS50 --type basic_pack --amount 2 --limit 50 --expires 2030-12-31T23:59:59Z
```

Параметры: `--code` — название, `--type` — `coins`, `basic_pack` или
`premium_pack`; `--amount` — количество монет или паков;
`--limit` — суммарное число **успешных активаций разными игроками**;
`--expires` — срок действия в формате UTC. Укажите хотя бы один предел
(`--limit` или `--expires`); можно оба. Команда откажется создать
дубликат кода. Не используйте зарезервированные префиксы `CF-` или `REF-`.

База: `echo_promo_codes` хранит настройки и счётчик,
`echo_promo_redemptions` хранит однократные активации.
Каждый игрок может получить каждый код только **один раз**.
Промокоды не заменяют реферальные и партнёрские коды.

**Важно:** при повторном вводе одного кода от того же аккаунта
показывается «Код уже активирован», даже если позднее истёк срок или
закончились активации. У другого аккаунта может быть другая причина отказа.

Для ручного отключения без удаления истории:

```sql
UPDATE echo_promo_codes SET active=false WHERE code='ECHO2026';
```

Ни один тестовый промокод автоматически при деплое не создаётся.
