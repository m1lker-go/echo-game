# app-ads.txt для ECHO (Android / RuStore)

ECHO и Cat Fighting используют общий домен `cat-fight.ru`. По правилам
app-ads.txt рекламные системы смотрят файл **в корне домена сайта разработчика**:

`https://cat-fight.ru/app-ads.txt`

**Источник текущего списка:** `m1lker-go/fight-club/client/app-ads.txt`.
Деплой Cat Fighting синхронизирует `client/` в `/var/www/html/` с помощью
`rsync`, поэтому этот файл должен оказываться в `/var/www/html/app-ads.txt`.
ECHO не должен публиковать конкурирующий файл по `/echo/app-ads.txt`
или перезаписывать содержимое чужого проекта.

В существующем файле есть строки, в частности:

```text
ads.vk.com, 30961603, direct
target.vk.ru, 30961603, direct
```

**Проверить у издателя:** идентификатор `30961603` и весь список должны
соответствовать рекомендациям раздела «Настройки → ads.txt и app-ads.txt»
в кабинете монетизации VK, который обслуживает ECHO. ID рекламных блоков
`2096987` и `2097075` не являются ID продавца для app-ads.txt.

## Проверка

- Открыть `https://cat-fight.ru/app-ads.txt` напрямую. Нужны HTTP 200 и
  обычный текст, не редирект и не HTML с игрой.
- Запустить `node scripts/check-app-ads.js` из корня репозитория ECHO.
  Скрипт только читает публичный URL, проверяет строки VK и не меняет VPS.
- На GitHub доступен workflow `Check shared app-ads.txt`. Он запускается
  по расписанию и вручную, а при неверном файле завершится ошибкой.
- Если файл недоступен, проверить публичный Nginx `root` / `location`,
  наличие `/var/www/html/app-ads.txt`, права на чтение и сайт разработчика
  в карточке ECHO в RuStore. Не меняйте Nginx и Cat Fighting вслепую.

**Ограничение:** корректный app-ads.txt не гарантирует показ объявлений.
Ошибка Android SDK `hasn't banners error` требует отдельной проверки
статуса ECHO/блоков в VK, рекламного спроса и тестового режима на устройстве.
